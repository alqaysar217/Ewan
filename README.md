# إيوان (Ewan) - منصة تصميم وتجارة الأثاث الذكية

هذا المشروع هو منصة متكاملة تربط بين العملاء، معارض الأثاث الكبرى، والحرفيين (النجارين والمصممين) في اليمن، مع دمج تقنيات الذكاء الاصطناعي لتسهيل تجربة التصميم الداخلي.

## 🚀 دليل التشغيل المحلي (للمطورين)

إذا قمت بتنزيل الكود من GitHub، اتبع الخطوات التالية لتشغيل المشروع في جهازك:

1. **تثبيت الملحقات**:
   افتح الـ Terminal في المجلد الرئيسي للمشروع ونفذ الأمر التالي:
   ```bash
   npm install
   ```

2. **إعداد ملف البيئة**:
   قم بإنشاء ملف جديد باسم `.env` في المجلد الرئيسي للمشروع وضع فيه مفتاحك السري:
   ```env
   OPENROUTER_API_KEY=sk-or-xxxxxxx...
   ```

3. **تشغيل المشروع**:
   نفذ الأمر التالي لبدء التشغيل:
   ```bash
   npm run dev
   ```

## 🛠 تعليمات الرفع على GitHub (حل مشكلة Authentication)

إذا واجهت خطأ `Invalid username or token` عند محاولة الرفع، اتبع هذه الخطوات:

1. **إنشاء مفتاح الوصول (Token)**:
   - ادخل لحسابك في GitHub.
   - اذهب إلى `Settings` -> `Developer Settings` -> `Personal access tokens` -> `Tokens (classic)`.
   - اضغط `Generate new token (classic)`.
   - حدد صلاحية `repo`.
   - انسخ التوكن (Token) الناتج.

2. **تحديث الرابط في الـ Terminal**:
   قم بتنفيذ الأمر التالي مع استبدال الكلمة ببياناتك:
   ```bash
   git remote set-url origin https://<انسخ_التوكن_هنا>@github.com/alqaysar217/Ewan.git
   ```

3. **الرفع مجدداً**:
   ```bash
   git add .
   git commit -m "تحديث شامل للنظام"
   git push origin main
   ```

## 🧠 المميزات التقنية
- **الذكاء الاصطناعي**: يعتمد على نموذج Gemma 2 المتاح عبر OpenRouter لتوليد نصائح تصميم وبرومبت (Prompt) فائق الدقة.
- **قاعدة البيانات**: Firebase Firestore لإدارة المتاجر والمنتجات والمستخدمين بشكل فوري.
- **التصميم**: استجابة كاملة للهواتف مع واجهات إدارية احترافية باستخدام ShadCN UI و Tailwind CSS.
